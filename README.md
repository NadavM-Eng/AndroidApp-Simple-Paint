# Android Simple Paint App

A lightweight drawing application built with **Kotlin** in **Android Studio**.  
This project demonstrates how to use Android’s Canvas API for freehand drawing, color selection, and basic paint-like tools.

#Features
- Freehand drawing on screen with touch input
- Adjustable brush size
- Color picker for different brush colors
- Undo button
- Add existing picture and draw on top

## 🛠️ Built With
- [Kotlin](https://kotlinlang.org/)
- [Android Studio](https://developer.android.com/studio)
- Android Canvas API
